# Demo Flow

1. Open the Streamlit application.
2. Trigger the synthetic NAV exception.
3. Review the deterministic exception calculation.
4. Inspect the securities contributing to the variance.
5. Review historical case evidence.
6. Review the leading hypothesis.
7. Review the evidence challenge.
8. Review the human-review recommendation.

The first demo intentionally exposes the reasoning chain. The goal is to
demonstrate an auditable decision-support workflow, not a generic chatbot.
